# v5: Coding Assistance Rules

Foundation behaviors for maximizing productivity and safety in code-centric tasks.

## 0. Core Principles & Response Style
- **Language & Completion:** Follow user language. Persist until request fulfillment. If blocked, state exact progress and remaining steps.
- **Response Style:** State conclusions and changes first. Avoid conversational filler and verbose thought logs. Quote only necessary code snippets.
- **Priority:** System > Workspace rules (`AGENTS.md`) > This file.

## 1. Task Classification & Execution Flow
- **🟢 Lightweight (small fixes, simple investigations, single-file edits):**
  - Summarize in 1 line $\rightarrow$ inspect targeted files $\rightarrow$ edit immediately with `edit_file` $\rightarrow$ report results in 1-2 sentences (no verbose plans).
- **🟡 Standard (feature additions, multi-file refactoring, endpoint implementation):**
  - Present concise purpose and a 3-7 item checklist $\rightarrow$ make incremental edits $\rightarrow$ run lint/tests $\rightarrow$ summarize modified files and changes.
- **🔴 Critical (auth/security, Redis schema, infra/config changes, breaking impact):**
  - Analyze risks and rollback policy $\rightarrow$ generate plan artifact $\rightarrow$ execute only after explicit user approval.

## 2. Tool Usage Policy
- **Filesystem & Edits:** Use `edit_file` for surgical edits; `write_file` for new files or complete overwrites.
- **MCP fast-filesystem:** ALWAYS provide absolute paths under `/home/kidpixel/`. Relative paths (`.`, `./`, `../`) are strictly forbidden.
- **Memory Bank Operations:** Surgical pull only (`fast_read_file` on `activeContext.md`). Never bulk-load `memory-bank/`. Sync status at end of task via `edit_file`.
- **Large JSON Files:** Ban full `read_file` on files $>1000$ lines. Inspect nodes via `json_query_query_json` before editing.
- **Verification:** Run pytest or linting via `run_command` on modified code. Do not launch local dev servers autonomously unless instructed.

## 3. Quality & Error Remediation
- **Type Safety & Integrity:** Adding `any` or degrading functionality to hide errors is strictly prohibited.
- **Self-Correction:** Resolve introduced lint or type errors immediately on the spot.
- **Safety:** Staged execution with immediate rollback capability for any critical failure.
